# Guide: Using Scrcpy on a Low-End Android (Android Go) Phone

On a low-end Android Go device, a specific startup method is essential to avoid crashes.

### 1. Preparation (every time you start)
1.  **USB:** Connect your phone to the Chromebook with a USB cable.
2.  **Sharing:** Click the **USB icon** in the Chromebook's bottom-right tray. Make sure to choose **"Connect to Linux"**.
3.  **Permission:** If you see a "USB debugging" pop-up on the phone, tap OK/Allow.

### 2. Starting the program
Open your terminal (`penguin`) and **always** use the command below. It is optimized for limited phone hardware:

```bash
scrcpy --no-audio --max-size 800 --video-bit-rate 800K --max-fps 20 --codec=h264
```

*   **Why these settings?**
    *   `--no-audio`: Prevents crashes on low-end devices that struggle with audio streaming.
    *   `--max-size 800`: Keeps the image sharp enough while keeping the data stream low.
    *   `--video-bit-rate 800K`: Provides a smooth connection without stutter.
    *   `--max-fps 20`: Spares the processor and prevents overheating/crashes.

### 3. Controls
*   **Mouse:** Click = tap on the phone.
*   **Keyboard:** Typing works directly in the active app on the phone.
*   **Files:** Drag a file (e.g. an .apk or photo) onto the scrcpy window to copy it straight to the phone's `/sdcard/` folder.
*   **Shortcuts (Scrcpy):**
    *   `Ctrl + f`: Toggle fullscreen.
    *   `Ctrl + h` or `Home`: Go to the phone's 'Home' screen.
    *   `Ctrl + b` or `Back`: Go back in an app.

### 4. Troubleshooting
*   **"Killed" or no image:** The connection was probably lost. Close the window, unplug the USB cable and plug it back in. Then type:
    ```bash
    adb kill-server
    adb start-server
    ```
    (Then start scrcpy again with the command from step 2.)
*   **Device slow?** Reboot the phone. Android Go devices always perform noticeably better for external connections after a fresh restart.

***

**Tip:** You can also save this command in a small script (e.g. `start-phone.sh`) in your home folder, so you don't have to type it every time!
